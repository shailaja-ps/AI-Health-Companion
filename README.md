# 🩺 AI Health Companion

An AI-powered healthcare companion that predicts possible diseases based on user symptoms using Machine Learning. The application provides an interactive dashboard, prediction history, analytics, and downloadable PDF reports.

## 🌐 Live Demo

**Frontend:** https://ai-health-companion-dusky.vercel.app/

**Backend API:** https://ai-health-companion-mk5a.onrender.com

**GitHub Repository:** https://github.com/Parniika2/AI-Health-Companion

---

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Parniika2/AI-Health-Companion.git
```

## Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Frontend

```bash
cd frontend
npm install
npm start
```

---

# 📡 API Endpoint

```
POST /predict
```

Accepts symptom inputs and returns the predicted disease.
